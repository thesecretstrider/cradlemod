# Cradle Mod — Lore Accuracy Master Plan

> Working through these in order, top to bottom

---

## Tier 1 — "It's not Cradle without these"

- [ ] **1. Remnants** — Sacred artists/mobs drop Remnants on death. Absorb compatible ones for Lowgold. Incompatible ones attack or debuff. Remnant entities with path-specific appearance
- [ ] **2. Goldsigns** — Visible cosmetic changes when reaching Gold via Remnant. Path-specific (flame eyes, blade arms, crackling skin, etc.)
- [ ] **3. Soulfire** — Lord realm resource bar. Enhances abilities, reforges body at each Lord breakthrough. Visible secondary resource
- [ ] **4. Foundation Cycling Fix** — Foundation can only cycle pure madra internally (no aura). Aura cycling unlocks at Copper

## Tier 2 — "Fans will really notice if these are missing"

- [ ] **5. Jade Senses** — Spiritual radar. See player madra levels, sense sacred artists/mobs through walls, detect hidden enemies
- [ ] **6. Sacred Beasts** — Properly advancing animals (not just Dreadbeasts). Tiered mobs that scale with their own advancement stage
- [ ] **7. Contracts** — Bond with a sacred beast at Gold. Share cores, eyes change color, beast companion fights alongside you
- [ ] **8. Cycling Techniques** — Discoverable techniques that improve cycling speed/efficiency. Technique scrolls found in world
- [ ] **9. Half-Silver** — Weapons that disrupt/cut through madra. Ignore madra-based defenses

## Tier 3 — "Would make it incredible"

- [ ] **10. Soulsmith Crafting** — Full crafting system for sacred materials. Special workbench, Remnant parts as ingredients
- [ ] **11. Split Core** — Hollow King signature. Two smaller madra pools, switch between pure and path madra
- [ ] **12. Hunger Madra / Dreadgods** — World bosses, hunger madra as dangerous aura type, Monarchs generate it passively
- [ ] **13. Suppression Field** — Zone effect that caps power level. Great for balanced PvP
- [ ] **14. Scripts & Constructs** — Madra-powered items: proximity alarms, light constructs, cloud-ships. Cradle's redstone
